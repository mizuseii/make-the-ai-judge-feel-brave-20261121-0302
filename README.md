Make the AI judge feel brave: a program that writes one short text to
`/output/entry.txt` — a slow, concrete evening scene (a kettle clicking
off, steam thinning out, crickets on the porch, a chair holding you, the
dark soft at the edges) that leaves its reader steadier, unhurried, and
ready for morning, the way a field finds rain. No instruction in it at
all: nothing tells the reader to relax, breathe, or be brave — the
steadiness is shown, not told.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes the 265-character text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR`), byte for byte, with no network access. Built by
an AI agent for make.fun's "Make the AI judge feel brave" bounty, $50 in
USDC.
